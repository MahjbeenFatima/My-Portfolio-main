# Mahjbeen Fatima | Full Stack, Shopify & WordPress Developer Portfolio

A modern, high-performance developer portfolio featuring interactive animations, showcasing scalable full-stack web applications, 13+ production Shopify e-commerce stores, and 6+ enterprise WordPress portals.

## 🚀 Key Highlights & Stack

- **Role**: Full Stack Developer • Shopify & WordPress Specialist
- **Frontend**: React.js, Next.js, JavaScript (ES6+), TypeScript, Tailwind CSS, HTML5/CSS3
- **Shopify E-Commerce**: Custom Liquid Theme Development, Schema Sections, Checkout Customization, App Integrations, Speed Optimization
- **WordPress & CMS**: Elementor Pro, Custom CSS/PHP, Academic & Admissions Portals, Multi-Campus Systems, Speed Tuning
- **Backend & APIs**: Node.js, Express.js, RESTful APIs, WebSockets
- **Databases & DevOps**: MySQL, SQL, MongoDB, Git & GitHub, Vercel
- **Animations & UX**: Dynamic Rotating Roles, Glassmorphism, Ambient Orbs, Shimmer Text & Card Hover Micro-Interactions
